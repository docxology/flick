# flick

Archive a public Flickr photostream as image files and JSON metadata sidecars.

Start with the [user guide](docs/README.md) for setup, account selection, and
output verification. The [technical manuscript](docs/manuscript/README.md)
describes the archiving method and includes reproducible render instructions.
